## 기능 명세서
### 1. 기능 정의

1.1. 기능명

- 공연 정보 등록 기능

1.2. 기능 설명 (요약)

- 공연 정보를 등록할 수 있는 기능을 구현한다. 이를 통해 판매자는 공연 정보를 등록할 수 있으며, 추후 구현될 공연정보 조회기능 및 티켓팅에 사용된다. 


### 2. 개발 배경 및 목표

2.1. 현황 및 문제점 (AS-IS)

- 현재 공연 정보 등록 기능이 없으며, 판매자가 공연 정보를 등록할 수 있는 방법이 없다. 이로 인해 판매자는 공연 정보를 등록하지 못하고, 사용자들은 공연 정보를 조회할 수 없다.

2.2. 개선 방향 및 기대 효과 (TO-BE)

- 공연 정보를 등록할 수 있는 기능을 구현한다. 이를 통해 판매자는 공연 정보를 등록할 수 있으며, 사용자들은 공연 정보를 조회할 수 있다. 또한, 공연 정보 등록 시 자동으로 판매자 정보가 연결되어 공연 정보의 신뢰성이 높아진다.

2.3. 핵심 목표

- 공연 정보 등록 기능 구현.

### 3. 구현할 기능 목록 (체크리스트)

3.1. 사용자 관점 기능

- 공연 정보 등록 페이지 접근
- 공연 정보 입력
  - 공연 제목
  - 공연 설명
  - 썸네일 이미지
  - 공연 날짜 및 시간
  - 공연 장소
  - 티켓 가격
    - 티켓 가격은 등급별로 차등 지정 가능
  - 등급별 티켓 수량

3.2. 시스템 관점 기능

- 판매자 정보 자동 연결
- 공연 정보 입력 시 내부적으로 수행되는 검증:
  - 공연 제목 중복 확인
  - 공연 날짜 및 시간 유효성 검사
  - 티켓 가격 유효성 검사 (음수, 0원 등 허용하지 않음)
  - 등급별 티켓 수량 유효성 검사 (0 이상)
  - 티켓 총 수량의 공연장 수용 가능 인원 초과 여부 확인

### 4. 상세 설계

4.1. 정책

- 공연 정보 등록 시 판매자 정보는 현재 로그인된 판매자의 정보로 자동 연결된다.
- 공연 정보 등록 시 입력된 공연 제목은 중복 확인을 거쳐야 하며, 중복된 경우 등록이 거부된다.
- 공연 날짜 및 시간은 유효한 형식이어야 하며, 과거 날짜는 허용되지 않는다.
- 티켓 가격은 0원 이하의 값은 허용되지 않으며, 등급별 티켓 수량은 0 이상이어야 한다.
- 티켓 총 수량은 공연장 수용 가능 인원을 초과할 수 없다.
- 썸네일 이미지는 필수 입력 사항이다.
- 존재하는 공연 장소가 아니면 등록이 거부된다.
- 공연 정보 등록 시 입력된 공연 장소는 사전에 등록된 장소 목록에서 선택해야 한다.
